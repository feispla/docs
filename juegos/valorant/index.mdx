## Vinculación de cuenta

Para empezar a rastrear tu rendimiento en VALORANT, vincula tu cuenta del juego desde el panel de VANTS. El proceso toma menos de un minuto y no requiere contraseñas: utilizamos la API oficial del juego para leer tus partidas clasificatorias y datos públicos de perfil.

Una vez conectada, VANTS sincroniza automáticamente tu historial de partidas, agentes jugados y resultados de cada mapa.

## Métricas destacadas

VANTS calcula las siguientes métricas para cada partida de VALORANT:

| Métrica | Descripción |
| --- | --- |
| ACS | Average Combat Score: puntos de combate por ronda |
| K/D | Ratio de eliminaciones por muerte |
| ADR | Daño promedio por ronda |
| KAST | Porcentaje de rondas con kill, assist, supervivencia o trade |
| HS% | Porcentaje de disparos a la cabeza |
| First Bloods | Primeras eliminaciones de la ronda |
| Clutches | Rondas ganadas en situación de desventaja numérica |

## Agrupación de datos

Todas tus métricas se organizan en tres dimensiones para que identifiques tus fortalezas y áreas de mejora:

- **Por mapa**: compara tu rendimiento en Ascent, Bind, Haven y el resto del pool competitivo.
- **Por agente**: analiza si tu K/D mejora con duelistas, controladores, iniciadores o centinelas.
- **Por ventana temporal**: filtra entre últimos 7 días, 30 días, 90 días o temporada completa.
