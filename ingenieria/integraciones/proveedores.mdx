VANTS conecta con proveedores de datos específicos para cada juego soportado. Esta página describe las fuentes válidas, los datos que aportan y los requisitos de autorización.

## Tabla de proveedores

| Juego | Proveedor | Datos | Autorización requerida |
| --- | --- | --- | --- |
| VALORANT | API oficial de Riot Games | Resultados, estadísticas de partidos, información de equipos y jugadores | Sí, requiere clave de API y acuerdo de uso |
| Counter-Strike 2 | Fuente autorizada por contrato | Resultados, brackets, estadísticas de series | Sí, requiere contrato con proveedor autorizado |
| League of Legends | API oficial de Riot Games | Partidos, jugadores, equipos, ligas regionales | Sí, requiere clave de API y acuerdo de uso |

## Datos importados por proveedor

### VALORANT

- Resultados de series con marcadores por mapa.
- Información de equipos participantes en ligas oficiales.
- Estadísticas agregadas de jugadores (rating, K/D, economía).
- Calendario de partidos programados.

### Counter-Strike 2

- Resultados de series con mapas jugados.
- Brackets de torneos con avance de equipos.
- Estadísticas de rendimiento por jugador.
- Datos de equipos y roster.

### League of Legends

- Resultados de partidos de ligas regionales.
- Información de campeones seleccionados.
- Estadísticas de jugadores y equipos.
- Calendario de temporadas y playoffs.

<Warning>
  No se permite scrapear HLTV, Liquipedia, FACEIT ni portales de VALORANT Esports. Estos sitios no autorizan la extracción automatizada de sus datos. VANTS solo usa fuentes con contrato explícito o API oficial con permisos válidos.
</Warning>

## Ciclo de sincronización

Los datos se sincronizan según la frecuencia acordada con cada proveedor:

- Partidos en vivo: actualización cada 30-60 segundos durante el horario de competición.
- Partidos programados: sincronización diaria.
- Estadísticas históricas: sincronización semanal o bajo demanda.
- Brackets de torneo: actualización tras cada ronda completada.

## Manejo de fallos

Si un proveedor no responde:

1. VANTS marca los datos como desactualizados.
2. La interfaz muestra la última versión conocida con indicador de antigüedad.
3. Se reintentan las consultas con backoff exponencial.
4. Si la falla persiste, se notifica al equipo de operaciones para revisar la integración.
