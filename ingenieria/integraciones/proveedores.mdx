<Note>
  **Estado: pendiente de confirmación.** Ningún proveedor está firmado ni activo todavía. Los nombres, datos y frecuencias de esta página son objetivos de diseño y se actualizarán cuando tengamos los datos oficiales de cada proveedor.
</Note>

</Warning>

## Requisitos para activar un proveedor

Antes de conectar cualquier fuente, debe cumplirse lo siguiente:

1. Acuerdo firmado o clave de API oficial con permisos válidos.
2. Documentación de los datos que entrega y sus límites de uso.
3. Frecuencia de actualización y límites de peticiones confirmados por el proveedor.
4. Adaptador que cumpla el contrato interno de [Integraciones](/ingenieria/integraciones).

## Ciclo de sincronización (objetivo)

Frecuencias orientativas. Se ajustarán a lo que permita cada proveedor una vez confirmado:

- Partidos en vivo: actualización cada 30-60 segundos durante el horario de competición.
- Partidos programados: sincronización diaria.
- Estadísticas históricas: sincronización semanal o bajo demanda.
- Brackets de torneo: actualización tras cada ronda completada.

## Manejo de fallos

Cuando un proveedor esté activo y no responda:

1. VANTS marca los datos como desactualizados.
2. La interfaz muestra la última versión conocida con indicador de antigüedad.
3. Se reintentan las consultas con backoff exponencial.
4. Si la falla persiste, se notifica al equipo de operaciones para revisar la integración.
