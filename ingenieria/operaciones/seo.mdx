VANTS genera metadatos y estructuras de SEO automáticamente para cada entidad de la plataforma. Esta página explica cómo se construyen las URLs, los metadatos y los datos estructurados que permiten que los buscadores indexen correctamente el contenido de esports.

## Metadatos dinámicos por entidad

Cada página de VANTS genera metadatos específicos según el tipo de contenido:

| Entidad | Title | Description | URL |
| --- | --- | --- | --- |
| Partido | \`Equipo A vs Equipo B | VANTS\` | Resultado, formato, estado y fecha del partido | `/match/{slug}` |
| Torneo | \`Nombre del Torneo | VANTS\` | Juego, formato, estado y premio del torneo | `/tournament/{slug}` |
| Equipo | \`Nombre del Equipo | VANTS\` | Región, juego, roster y estadísticas recientes | `/team/{slug}` |
| Jugador | \`Nickname | VANTS\` | Juego, equipo, región y rating actual | `/player/{slug}` |
| Noticia | \`Título de la noticia | VANTS\` | Resumen de 160 caracteres y fecha | `/news/{slug}` |

## Canonical URLs

Cada página incluye una etiqueta `<link rel="canonical">` que apunta a la URL definitiva del contenido. Esto evita contenido duplicado cuando el mismo partido es accesible por múltiples rutas (por ejemplo, con parámetros de tracking).

## Open Graph

Las páginas de VANTS generan etiquetas Open Graph para compartir en redes sociales:

- `og:title`: coincide con el title de la página.
- `og:description`: coincide con la description.
- `og:type`: `website` para páginas generales, `article` para noticias.
- `og:image`: imagen representativa del contenido (banner de torneo, logo de equipo, portada de noticia).
- `og:url`: URL canónica completa.

## Sitemap

VANTS genera un sitemap XML dinámico que incluye:

- Páginas estáticas principales.
- Partidos completados de los últimos 30 días.
- Torneos activos, próximos y finalizados de los últimos 90 días.
- Equipos y jugadores con perfil público.
- Noticias publicadas.

El sitemap se actualiza automáticamente tras cada cambio de estado de partido o publicación de noticia.

## Robots.txt

El archivo `robots.txt` de VANTS permite el rastreo de contenido público y bloquea rutas internas:

```text
User-agent: *
Allow: /
Disallow: /admin/
Disallow: /api/internal/
Disallow: /profile/
```

<Warning>
  No indexar `/profile/*`. Las páginas de perfil de usuario contienen información personal y configuraciones privadas que no deben aparecer en resultados de búsqueda. Asegurate de que estas rutas tengan `noindex` y estén bloqueadas en robots.txt.
</Warning>

## Datos estructurados

VANTS inyecta JSON-LD con tipos de schema.org cuando corresponde:

### SportsEvent (partido)

```json
{
  "@context": "https://schema.org",
  "@type": "SportsEvent",
  "name": "Eclipse Core vs Nova Strike",
  "startDate": "2024-01-15T18:00:00Z",
  "sport": "VALORANT",
  "homeTeam": { "@type": "SportsTeam", "name": "Eclipse Core" },
  "awayTeam": { "@type": "SportsTeam", "name": "Nova Strike" }
}
```

### NewsArticle (noticia)

```json
{
  "@context": "https://schema.org",
  "@type": "NewsArticle",
  "headline": "Título de la noticia",
  "datePublished": "2024-01-10T12:00:00Z",
  "author": { "@type": "Organization", "name": "VANTS" }
}
```

### Person (jugador)

```json
{
  "@context": "https://schema.org",
  "@type": "Person",
  "name": "Nickname del jugador",
  "memberOf": { "@type": "SportsTeam", "name": "Eclipse Core" }
}
```

### SportsTeam (equipo)

```json
{
  "@context": "https://schema.org",
  "@type": "SportsTeam",
  "name": "Eclipse Core",
  "sport": "VALORANT"
}
```

## Slugs estables y humanos

Las URLs de VANTS usan slugs generados a partir del nombre de la entidad:

- Partido: `eclipse-core-vs-nova-strike-2024-01-15`
- Torneo: `vants-pro-circuit-2024`
- Equipo: `eclipse-core`
- Jugador: `nickname-del-jugador`
- Noticia: `titulo-de-la-noticia-en-minusculas`

Los slugs nunca cambian una vez publicados. Si el nombre de una entidad cambia, se mantiene el slug original y se añade una redirección 301 si es necesario.

## Página 404 con sugerencias

Cuando una URL no existe, VANTS muestra una página 404 que:

- Explica que el contenido no fue encontrado.
- Sugiere páginas similares basadas en el slug (por ejemplo, si buscaste un equipo, sugiere equipos con nombres parecidos).
- Incluye un buscador para encontrar el contenido correcto.
- Mantiene la navegación principal para no interrumpir la sesión del usuario.
