VANTS permite a cada usuario crear una lista personal de seguimiento con equipos, jugadores, torneos y partidos de interes. Esta pagina describe la tabla que almacena esas preferencias y las recomendaciones para consultarlas de forma eficiente.

El sistema de favoritos es la base de notificaciones personalizadas, feeds de contenido y accesos directos en el panel de perfil.

## Tabla de favoritos

La tabla `favorites` guarda una fila por cada entidad que un usuario decide seguir.

```sql
CREATE TABLE favorites (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id      UUID NOT NULL REFERENCES users(id),
  entity_type  VARCHAR(30) NOT NULL,
  entity_id    UUID NOT NULL,
  created_at   TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at   TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

| Columna | Tipo | Descripcion |
| --- | --- | --- |
| `user_id` | UUID | Usuario que guarda el favorito |
| `entity_type` | VARCHAR(30) | Tipo de entidad seguida |
| `entity_id` | UUID | Identificador de la entidad en su tabla origen |
| `created_at` | TIMESTAMPTZ | Fecha en que se agrego a favoritos |

## Tipos de entidad soportados

La columna `entity_type` acepta los siguientes valores, que determinan a que tabla apunta `entity_id`:

| Valor de `entity_type` | Tabla destino | Ejemplo de uso |
| --- | --- | --- |
| `team` | `teams` | Seguir a Eclipse Core |
| `player` | `users` o tabla de jugadores | Seguir a un jugador profesional |
| `tournament` | `tournaments` | Recibir alertas de un torneo |
| `match_series` | `match_series` | Recibir actualizaciones de un partido |

## Consultas comunes

Para obtener todos los equipos favoritos de un usuario:

```sql
SELECT f.entity_id, t.name, t.slug, t.logo_url
FROM favorites f
JOIN teams t ON f.entity_id = t.id
WHERE f.user_id = 'uuid-del-usuario'
  AND f.entity_type = 'team';
```

Para contar cuantos usuarios siguen un torneo especifico:

```sql
SELECT COUNT(*) AS followers
FROM favorites
WHERE entity_type = 'tournament'
  AND entity_id = 'uuid-del-torneo';
```

<Tip>
  Crea un indice compuesto sobre `(user_id, entity_type)` para que las consultas de perfil sean rapidas. Si permites buscar quien sigue una entidad, anade tambien un indice sobre `(entity_type, entity_id)`.
</Tip>

## Integridad referencial flexible

La tabla `favorites` no usa claves foraneas directas sobre `entity_id` porque apunta a varias tablas distintas. La aplicacion valida que la combinacion de `entity_type` y `entity_id` sea correcta antes de insertar. Cuando una entidad se elimina, un worker en segundo plano limpia las filas de `favorites` correspondientes.

<Warning>
  No anadas restricciones de clave foranea sobre `entity_id` a nivel de base de datos, ya que violarian la flexibilidad del polimorfismo. Maneja la integridad en la capa de aplicacion.
</Warning>
