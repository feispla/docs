Los partidos son el nucleo de la experiencia competitiva en VANTS. Esta pagina describe las tres tablas que modelan una serie completa: la serie en si, cada mapa o juego individual dentro de ella, y el rendimiento de cada jugador.

El flujo de un partido atraviesa varios estados que la plataforma expone al usuario con etiquetas claras en español.

## Estados de un partido

VANTS usa los siguientes estados internos, que se muestran al usuario con etiquetas traducidas:

| Slug interno | Etiqueta visible | Significado |
| --- | --- | --- |
| `scheduled` | Programado | Fecha y hora confirmadas, aun no comienza |
| `check_in` | Check-in | Periodo de confirmacion de asistencia activo |
| `live` | En vivo | El partido esta en curso |
| `paused` | Pausado | El partido se ha detenido temporalmente |
| `delayed` | Aplazado | Inicio retrasado respecto a la hora programada |
| `completed` | Finalizado | Resultado confirmado y estadisticas registradas |
| `cancelled` | Cancelado | El partido no se jugara y no cuenta para standings |
| `forfeited` | W.O. | Un equipo no se presento; victoria administrativa |
| `disputed` | En disputa | Resultado cuestionado, pendiente de revision |

## Tabla de series de partido

La tabla `match_series` representa el enfrentamiento completo entre dos equipos.

```sql
CREATE TABLE match_series (
  id                  UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  slug                VARCHAR(150) NOT NULL UNIQUE,
  tournament_id       UUID REFERENCES tournaments(id),
  tournament_stage_id UUID REFERENCES tournament_stages(id),
  game_id             UUID NOT NULL REFERENCES games(id),
  region_id           UUID NOT NULL REFERENCES regions(id),
  status              VARCHAR(30) NOT NULL DEFAULT 'scheduled',
  format              VARCHAR(20) NOT NULL,
  best_of             SMALLINT NOT NULL DEFAULT 1,
  scheduled_at        TIMESTAMPTZ,
  started_at          TIMESTAMPTZ,
  completed_at        TIMESTAMPTZ,
  team_a_id           UUID NOT NULL REFERENCES teams(id),
  team_b_id           UUID NOT NULL REFERENCES teams(id),
  team_a_score        SMALLINT NOT NULL DEFAULT 0,
  team_b_score        SMALLINT NOT NULL DEFAULT 0,
  winner_team_id      UUID REFERENCES teams(id),
  stream_url          TEXT,
  created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

| Columna | Descripcion |
| --- | --- |
| `format` | Tipo de competicion, como liga o eliminatoria |
| `best_of` | Numero maximo de mapas: 1, 3 o 5 |
| `team_a_score` / `team_b_score` | Mapas ganados por cada equipo |
| `winner_team_id` | Equipo ganador una vez finalizado |
| `stream_url` | Enlace a la transmision en vivo |

## Tabla de mapas o juegos individuales

La tabla `match_maps_or_games` almacena cada mapa o partida dentro de una serie.

```sql
CREATE TABLE match_maps_or_games (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  series_id       UUID NOT NULL REFERENCES match_series(id),
  sequence        SMALLINT NOT NULL DEFAULT 1,
  name            VARCHAR(100),
  team_a_score    SMALLINT NOT NULL DEFAULT 0,
  team_b_score    SMALLINT NOT NULL DEFAULT 0,
  winner_team_id  UUID REFERENCES teams(id),
  started_at      TIMESTAMPTZ,
  completed_at    TIMESTAMPTZ,
  metadata        JSONB,
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

La columna `metadata` de tipo JSONB guarda datos especificos del juego, como agentes seleccionados, rondas ganadas por bando o estadisticas detalladas por ronda, sin forzar un esquema rigido.

## Tabla de jugadores por partido

La tabla `match_players` registra la actuacion individual de cada jugador en una serie.

```sql
CREATE TABLE match_players (
  id               UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  match_series_id  UUID NOT NULL REFERENCES match_series(id),
  game_account_id  VARCHAR(100),
  user_id          UUID REFERENCES users(id),
  team_id          UUID NOT NULL REFERENCES teams(id),
  side             VARCHAR(20),
  won              BOOLEAN,
  kills            SMALLINT NOT NULL DEFAULT 0,
  deaths           SMALLINT NOT NULL DEFAULT 0,
  assists          SMALLINT NOT NULL DEFAULT 0,
  score            INTEGER,
  rating_change    INTEGER,
  stats_json       JSONB,
  created_at       TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at       TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

| Columna | Descripcion |
| --- | --- |
| `side` | Bando o faccion asignada en el mapa |
| `score` | Puntuacion interna del juego para desempates |
| `rating_change` | Variacion de rating VANTS tras el partido |
| `stats_json` | Estadisticas adicionales en formato flexible |

<Tip>
  El `rating_change` es un numero entero que varia segun el juego. Nunca se mezclan ratings de distintos titulos en una misma comparacion.
</Tip>
