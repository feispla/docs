Las entidades base de VANTS son los bloques de construccion sobre los que descansan los datos competitivos. Esta pagina describe las tablas que definen juegos, regiones geograficas, equipos y las relaciones entre jugadores y equipos.

Sin estas tablas, no seria posible vincular un partido a un juego concreto, asignar un equipo a una region o saber quien forma parte de una plantilla en un momento dado.

## Tabla de juegos

La tabla `games` registra cada titulo competitivo soportado por la plataforma.

```sql
CREATE TABLE games (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  slug       VARCHAR(50) NOT NULL UNIQUE,
  name       VARCHAR(100) NOT NULL,
  active     BOOLEAN NOT NULL DEFAULT TRUE,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

| Columna | Tipo | Descripcion |
| --- | --- | --- |
| `id` | UUID | Identificador unico del juego |
| `slug` | VARCHAR(50) | Clave legible y permanente para URLs |
| `name` | VARCHAR(100) | Nombre visible del juego |
| `active` | BOOLEAN | Indica si el juego esta habilitado en la plataforma |
| `created_at` | TIMESTAMPTZ | Fecha de alta del registro |
| `updated_at` | TIMESTAMPTZ | Fecha de ultima modificacion |

## Tabla de regiones

La tabla `regions` define las zonas geograficas para clasificar equipos, torneos y rankings.

```sql
CREATE TABLE regions (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  slug       VARCHAR(50) NOT NULL UNIQUE,
  name       VARCHAR(100) NOT NULL,
  timezone   VARCHAR(50) NOT NULL DEFAULT 'UTC',
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

Ejemplos de regiones: Global, Norteamérica, LATAM, Europa, Brasil, Asia.

## Tabla de equipos

La tabla `teams` almacena la informacion de cada equipo registrado en VANTS.

```sql
CREATE TABLE teams (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  slug        VARCHAR(100) NOT NULL UNIQUE,
  name        VARCHAR(150) NOT NULL,
  tag         VARCHAR(20),
  game_id     UUID NOT NULL REFERENCES games(id),
  region_id   UUID NOT NULL REFERENCES regions(id),
  logo_url    TEXT,
  banner_url  TEXT,
  verified_at TIMESTAMPTZ,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

| Columna | Tipo | Descripcion |
| --- | --- | --- |
| `slug` | VARCHAR(100) | Identificador legible para URLs |
| `tag` | VARCHAR(20) | Abreviatura del equipo, como Eclipse Core o Nova Strike |
| `game_id` | UUID | Juego al que esta asociado el equipo |
| `region_id` | UUID | Region de competencia del equipo |
| `logo_url` | TEXT | URL del escudo o logo del equipo |
| `banner_url` | TEXT | URL de la imagen de portada |
| `verified_at` | TIMESTAMPTZ | Fecha de verificacion; NULL si no esta verificado |

## Tabla de membresias de equipo

La tabla `team_memberships` registra quien pertenece a un equipo y en que rol.

```sql
CREATE TABLE team_memberships (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  team_id    UUID NOT NULL REFERENCES teams(id),
  user_id    UUID NOT NULL REFERENCES users(id),
  role       VARCHAR(50) NOT NULL DEFAULT 'player',
  joined_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  left_at    TIMESTAMPTZ,
  active     BOOLEAN NOT NULL DEFAULT TRUE,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

Un jugador puede aparecer en varias filas si cambia de equipo a lo largo del tiempo. La columna `active` indica si la membresia esta vigente. Cuando un jugador sale del equipo, `left_at` se completa y `active` pasa a FALSE.
