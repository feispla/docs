VANTS es una plataforma competitiva de esports que une información de partidos, torneos, rankings y noticias en una sola experiencia web. Esta página describe la arquitectura de alto nivel que permite a los usuarios seguir competiciones de forma fluida, sin importar el juego o la región.

La plataforma se divide en cinco capas principales que trabajan en conjunto para entregar datos actualizados y una interfaz rápida.

## Capas de la arquitectura

### Frontend web

La interfaz de VANTS es una aplicación web que consume la API interna. El código se divide por rutas para cargar solo lo necesario en cada página. Los usuarios navegan por calendarios, rankings, estadísticas y perfiles sin recargas completas.

### API interna

La API expone endpoints que alimentan al frontend. Actua como puente entre la interfaz y los datos, aplicando reglas de negocio como filtros por región, juego o estado de partido. No expone directamente los proveedores externos.

### Capa de datos competitivos desacoplada

Los datos de partidos, torneos y jugadores provienen de fuentes externas, pero VANTS los normaliza en su propio modelo. Esta capa desacoplada permite cambiar proveedores sin afectar al frontend ni a la experiencia del usuario.

### Workers de ingesta

Procesos en segundo plano que recogen información de partidos en vivo, resultados y cambios de standings. Los workers transforman los datos al formato interno y los guardan en la base de datos principal.

### CMS de noticias

El sistema de gestión de contenido permite a los editores publicar articulos sobre torneos, equipos y jugadores. Las noticias se vinculan con entidades del modelo de datos, como torneos o equipos, para mantener el contexto competitivo.
