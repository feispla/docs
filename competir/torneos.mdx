En VANTS el acceso a los torneos depende de tu plan. Además, en el servidor de Discord tienes comandos para consultar rankings, jugadores y torneos, sincronizados con la web en tiempo real.

## Torneos por plan

| Torneo | Plan necesario |
| --- | --- |
| VANT Open | VANT BASIC o superior |
| Pro Series | VANT PRO o superior |
| Elite Invitational | VANT ELITE |

Consulta los precios en [Planes](/monetizacion/planes).

## Discord

| Comando | Qué hace |
| --- | --- |
| `/ranked` | Consulta el ranking |
| `/jugador` | Consulta el perfil de un jugador |
| `/torneo` | Consulta información de un torneo |

Los datos se sincronizan con la web en tiempo real. Únete al servidor en [discord.gg/rCHE7jvRS4](https://discord.gg/rCHE7jvRS4).
