El centro de noticias de VANTS reúne todo el contenido editorial de la plataforma. Desde aquí puedes acceder a análisis, resultados, entrevistas y anuncios organizados por categoría y juego. Cada artículo está optimizado para compartir en redes sociales con metadatos SEO y Open Graph generados automáticamente.

## Categorías de contenido

Los artículos se clasifican en las siguientes categorías:

| Categoría | Descripción |
| --- | --- |
| Noticias | Información general sobre el ecosistema competitivo |
| Análisis | Desglose táctico de partidos, series o metas |
| Resultados | Resumen de partidos y torneos recientes |
| Anuncios de torneo | Presentación de nuevos eventos en VANTS |
| Cambios de formato | Actualizaciones en reglas, formatos de serie o clasificación |
| Perfiles de jugadores | Historias y trayectorias de competidores |
| Entrevistas | Conversaciones con jugadores, entrenadores y casters |
| Recaps | Resumen semanal o mensual de la actividad en la plataforma |
| Guías | Contenido educativo para mejorar en los juegos soportados |
| Actualizaciones de plataforma | Novedades en funciones, diseño o reglas de VANTS |

## Filtros disponibles

La barra lateral del centro de noticias permite filtrar por:

- **Categoría**: selección múltiple de las opciones anteriores
- **Juego**: VALORANT, Counter-Strike 2, League of Legends o general
- **Torneo**: eventos específicos relacionados con los artículos
- **Fecha**: hoy, esta semana, este mes, año en curso

## Listado de artículos

Cada tarjeta del listado muestra:

- Imagen de portada (propia o licenciada)
- Título del artículo
- Extracto de 140 caracteres
- Categoría y juego relacionado
- Fecha de publicación
- Autor
- Tiempo estimado de lectura

## Metadatos SEO y Open Graph

Cada artículo genera automáticamente estos metadatos:

| Metadato | Fuente |
| --- | --- |
| SEO title | Campo dedicado o título del artículo |
| SEO description | Campo dedicado o extracto del artículo |
| Open Graph title | SEO title o título |
| Open Graph description | SEO description o extracto |
| Open Graph image | Imagen de portada del artículo |
| Canonical URL | URL permanente del artículo en VANTS |

Los editores pueden personalizar el SEO title y description desde el panel de administración para optimizar el posicionamiento sin alterar el título visible del artículo.

<Tip>
  Usa la combinación de filtros "Análisis" + juego específico para encontrar contenido táctico actualizado sobre el meta competitivo de tu título favorito.
</Tip>
