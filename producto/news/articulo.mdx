Cada artículo del centro de noticias de VANTS sigue una estructura unificada que garantiza consistencia visual, optimización para buscadores y facilidad de navegación. En esta página encontrarás el modelo de datos completo, los estados editoriales y los elementos de navegación relacionada.

## Modelo de datos de un artículo

| Campo | Tipo | Descripción |
| --- | --- | --- |
| id | UUID | Identificador único interno |
| slug | string | URL amigable, único por artículo |
| título | string | Título visible en la página y listados |
| extracto | string | Resumen de 140 caracteres para tarjetas y SEO |
| contenido | markdown | Cuerpo del artículo con formato enriquecido |
| autor | string | Nombre del redactor o fuente |
| imagen de portada | URL | Imagen propia o licenciada para encabezado y Open Graph |
| juego | enum | VALORANT, CS2, LoL o null si es general |
| torneo relacionado | string | Slug del torneo mencionado (opcional) |
| equipo relacionado | string | Slug del equipo mencionado (opcional) |
| jugador relacionado | string | Slug del jugador mencionado (opcional) |
| fecha de publicación | datetime | Momento de aparición pública |
| fecha de actualización | datetime | Última modificación del contenido |
| estado | enum | borrador, programado, publicado, archivado |
| SEO title | string | Título optimizado para motores de búsqueda |
| SEO description | string | Descripción optimizada para motores de búsqueda |

## Estados editoriales

Los artículos pasan por estos estados durante su ciclo de vida:

<Steps>
  <Step title="Borrador">
    El artículo está en redacción. Solo visible para editores con permisos de contenido. No genera URL pública ni metadatos SEO.
  </Step>
  <Step title="Programado">
    El contenido está listo y tiene una fecha de publicación futura. Se publica automáticamente en el horario indicado.
  </Step>
  <Step title="Publicado">
    El artículo es visible públicamente, indexable por buscadores y aparece en el centro de noticias con los filtros correspondientes.
  </Step>
  <Step title="Archivado">
    El artículo deja de aparecer en listados principales pero mantiene su URL activa. Útil para contenido de temporadas pasadas que ya no es relevante en la portada.
  </Step>
</Steps>

## Estructura de la página de artículo

La ruta pública de cada artículo sigue el patrón `/news/:articleSlug`. La página se compone de:

1. **Imagen de portada**: ancho completo, con atribución si es licenciada
2. **Encabezado**: título, autor, fecha de publicación y tiempo de lectura
3. **Categoría y juego**: etiquetas clickeables que filtran al centro de noticias
4. **Contenido**: cuerpo en markdown con soporte para imágenes incrustadas, tablas y citas
5. **Entidades relacionadas**: enlaces a torneo, equipo o jugador mencionados
6. **Artículos relacionados**: hasta 4 artículos del mismo juego o categoría

## Artículos relacionados

VANTS selecciona automáticamente artículos relacionados usando este orden de prioridad:

1. Mismo juego + misma categoría + fecha reciente
2. Mismo juego + categoría diferente + fecha reciente
3. Categoría igual + juego diferente + fecha reciente
4. Cualquier artículo reciente si no hay coincidencias anteriores

## Datos estructurados

Cada artículo publicado incluye datos estructurados JSON-LD para mejorar la indexación:

```json
{
  "@context": "https://schema.org",
  "@type": "NewsArticle",
  "headline": "Título del artículo",
  "description": "Extracto del artículo",
  "author": {
    "@type": "Person",
    "name": "Nombre del autor"
  },
  "datePublished": "2025-01-15T10:00:00Z",
  "dateModified": "2025-01-15T12:00:00Z",
  "image": "https://vants.example/images/article-cover.jpg"
}
```

<Note>
  Los campos SEO title y SEO description son opcionales. Si no se completan, VANTS usa el título y el extracto como valores por defecto.
</Note>
