El resumen de torneo en VANTS condensa toda la información esencial de una competición en una sola vista. Aquí encontrarás los datos administrativos, las reglas resumidas, los requisitos de participación y las fases que componen el formato del torneo.

## Campos del resumen

La vista de resumen muestra los siguientes campos organizados en secciones:

### Información general

| Campo | Descripción |
| --- | --- |
| Nombre | Título completo del torneo |
| Juego | VALORANT, Counter-Strike 2 o League of Legends |
| Organizador | Entidad o comunidad que gestiona la competición |
| Región | Área geográfica del torneo: Global, Norteamérica, LATAM, Europa, Brasil, Asia |
| Fechas | Fecha de inicio, fin y cierre de inscripciones |
| Formato | Estructura de la serie: BO1, BO3 o BO5 |
| Premio | Descripción del pool de recompensas |
| Estado | Etiqueta visual del estado actual del torneo |
| Participantes | Número de equipos inscritos y cupo máximo |

### Reglas resumidas

- Reglamento general de la competición
- Sistema de puntuación y desempate
- Política de W.O. y partidos aplazados
- Procedimiento de disputas y apelaciones

### Requisitos de elegibilidad

| Requisito | Descripción |
| --- | --- |
| Edad mínima | Edad requerida para participar |
| Región | Restricciones geográficas de participación |
| Conducta | Cumplimiento del código de conducta de VANTS |
| Enlace de soporte | Contacto para dudas sobre elegibilidad |

<Info>
  El enlace de soporte dirige a un canal de atención donde los equipos pueden resolver dudas sobre requisitos de participación antes de inscribirse.
</Info>

## Fases soportadas

VANTS admite múltiples formatos de fase que pueden combinarse dentro de un mismo torneo. Las fases disponibles son:

- **Eliminación directa**: formato de bracket de una sola eliminación.
- **Doble eliminación**: bracket con rama de ganadores y rama de perdedores.
- **Round robin**: todos contra todos en un grupo.
- **Fase de grupos**: múltiples grupos con round robin interno.
- **Swiss**: sistema suizo con emparejamiento por récord.
- **Liga**: competición prolongada con calendario de jornadas.
- **Clasificatorio abierto**: inscripción libre para cualquier equipo.
- **Clasificatorio cerrado**: invitación o requisito de clasificación previa.
- **Playoffs**: fase final tras una clasificación previa.
- **Final**: enfrentamiento decisivo del torneo.
- **Showmatch**: partido de exhibición sin impacto en la clasificación.
