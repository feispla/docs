La pestaña de partidas en tu perfil de VANTS muestra todo tu historial competitivo personal. Desde aquí puedes revisar resultados pasados, filtrar por múltiples criterios y marcar partidas como favoritas para encontrarlas rápidamente más adelante.

## Filtros disponibles

El historial personal usa los mismos filtros que el feed global de partidos de VANTS:

| Filtro | Opciones |
| --- | --- |
| Juego | VALORANT, Counter-Strike 2, League of Legends |
| Temporada | Temporada actual o anteriores |
| Región | Global, Norteamérica, LATAM, Europa, Brasil, Asia |
| Torneo | Todos los torneos, oficiales VANTS, comunidad, clasificatorios |
| Equipo | Equipos contra los que has jugado |
| Formato | BO1, BO3, BO5 |
| Estado | Programado, En vivo, Finalizado, Cancelado, W.O., En disputa |
| Periodo | 7 días, 30 días, temporada completa, histórico |
| Resultado | Victoria, derrota, ambos |

## Tabla de partidas

Cada fila del historial muestra:

| Columna | Descripción |
| --- | --- |
| Fecha | Día y hora del partido |
| Torneo | Nombre del evento con enlace |
| Rival | Equipo contrario con enlace a su ficha |
| Resultado | Victoria o derrota con marcador |
| Formato | BO1, BO3 o BO5 |
| Estado | Etiqueta visual del estado actual |
| Juego | Icono del título |
| Favorito | Estrella para marcar o desmarcar |

## Marcado de partidos favoritos

Puedes marcar cualquier partido finalizado como favorito haciendo clic en la estrella de su fila. Las partidas favoritas se destacan visualmente y puedes filtrar el historial para mostrar solo esas entradas.

Usos comunes del marcado de favoritos:

- Guardar series memorables contra rivales específicos
- Marcar partidos donde alcanzaste un rating histórico
- Reservar partidos para revisión táctica posterior
- Identificar rápidamente tus mejores rendimientos individuales

## Estados de partido

Los partidos en tu historial pueden tener estos estados visuales:

| Estado (slug) | Etiqueta visible |
| --- | --- |
| scheduled | Programado |
| check_in | Check-in |
| live | En vivo |
| paused | Pausado |
| delayed | Aplazado |
| completed | Finalizado |
| cancelled | Cancelado |
| forfeited | W.O. |
| disputed | En disputa |

## Acciones por partido

Al hacer clic en una fila, accedes a la ficha detallada del partido donde puedes:

- Revisar el marcador ronda por ronda (o minuto a minuto en LoL)
- Ver estadísticas individuales de todos los jugadores
- Descargar el demo si está disponible
- Compartir el enlace al partido

<Note>
  Los partidos con estado "En disputa" permanecen en tu historial pero sin resultado definitivo hasta que el equipo de soporte de VANTS resuelva la incidencia.
</Note>
