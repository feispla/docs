VANTS canaliza las solicitudes de colaboración y programación a un canal privado de Discord mediante un webhook. No requiere bot ni servidor propio: el formulario público envía el mensaje directamente al canal, y solo el equipo puede leerlo.

<Info>
  Este flujo evita mantener un bot 24/7. Es la opción recomendada para empezar. Si más adelante necesitas lógica personalizada (respuestas automáticas, comandos slash), migra a un bot con `discord.js`.
</Info>

## Arquitectura

```text
Formulario público (Tally / Fillout / propio)
        │  POST JSON
        ▼
Webhook de Discord (URL secreta)
        │
        ▼
Canal privado #leads-colab
```

## 1. Crear el canal privado

<Steps>
  <Step title="Nuevo canal">
    En tu servidor Discord, **Crear canal** con nombre `leads-colab`. Marca **Canal privado**.
  </Step>
  <Step title="Añade solo al equipo">
    Da acceso únicamente a los roles `@equipo VANTS`, `@Admin` y `@Moderador`. Nadie más debe leerlo.
  </Step>
  <Step title="Verifica permisos">
    Comprueba que los miembros normales del servidor no ven el canal desde una cuenta de prueba.
  </Step>
</Steps>

## 2. Crear el webhook

<Steps>
  <Step title="Abre ajustes del canal">
    Click derecho en `#leads-colab` → **Editar canal** → **Integraciones** → **Webhooks**.
  </Step>
  <Step title="Nuevo webhook">
    Pulsa **Nuevo webhook**. Nombre sugerido: `VANTS Colaboradores`. Avatar: logo de VANTS.
  </Step>
  <Step title="Copia la URL">
    Pulsa **Copiar URL de webhook**. Formato:
    ```text
    https://discord.com/api/webhooks/<WEBHOOK_ID>/<WEBHOOK_TOKEN>
    ```
  </Step>
</Steps>

<Warning>
  La URL del webhook es un secreto. Cualquiera que la tenga puede publicar en el canal. **No la publiques en el repositorio, capturas, ni en esta documentación.** Guárdala en un gestor de secretos o variable de entorno.
</Warning>

## 3. Conectar un formulario

<Tabs>
  <Tab title="Tally (recomendado)">
    <Steps>
      <Step title="Crea el formulario">
        En [tally.so](https://tally.so) crea un formulario con los campos: Nombre, Rol (Desarrollador, Socio, Streamer, Donante), Email, Propuesta, Enlaces.
      </Step>
      <Step title="Integra Discord">
        En **Integrations** → **Discord**, pega la URL del webhook.
      </Step>
      <Step title="Publica y enlaza">
        Copia el enlace público del formulario y ponlo en el CTA de las páginas de contacto.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Fillout">
    <Steps>
      <Step title="Crea el formulario">
        En [fillout.com](https://fillout.com) crea el formulario con los mismos campos.
      </Step>
      <Step title="Integra Discord">
        Ajustes → **Integrations** → **Discord webhook** → pega la URL.
      </Step>
      <Step title="Publica">
        Comparte el enlace del formulario en las páginas de contacto.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Petición HTTP propia">
    Desde tu backend o una función serverless (Vercel, Cloudflare Workers), envía un `POST`:

    ```bash cURL
    curl -X POST "$DISCORD_WEBHOOK_URL" \
      -H "Content-Type: application/json" \
      -d '{
        "username": "VANTS Colaboradores",
        "embeds": [{
          "title": "Nueva solicitud",
          "color": 14877715,
          "fields": [
            { "name": "Nombre",    "value": "Ada Lovelace", "inline": true },
            { "name": "Rol",       "value": "Desarrolladora", "inline": true },
            { "name": "Email",     "value": "ada@example.com" },
            { "name": "Propuesta", "value": "Overlay de bracket para CS2." },
            { "name": "Enlaces",   "value": "https://github.com/ada" }
          ]
        }]
      }'
    ```

    Guarda `DISCORD_WEBHOOK_URL` como variable de entorno secreta.
  </Tab>
</Tabs>

## 4. Formato del mensaje

Usa un **embed** con el color primario de VANTS (`#E30613` → `14877715` en decimal) y estos campos mínimos:

| Campo     | Obligatorio | Nota                                              |
| --------- | ----------- | ------------------------------------------------- |
| Nombre    | Sí          | Nombre o alias del contacto.                      |
| Rol       | Sí          | Desarrollador, Socio, Streamer, Donante, Otro.    |
| Email     | Sí          | Para responder fuera de Discord.                  |
| Propuesta | Sí          | Descripción breve, máximo 500 caracteres.         |
| Enlaces   | No          | GitHub, Twitch, portfolio, deck.                  |

## 5. Buenas prácticas

<AccordionGroup>
  <Accordion title="Rate limit" icon="gauge">
    Discord limita a 30 mensajes por minuto por webhook. Un formulario público normal está muy lejos de ese límite; si prevés picos, añade una cola simple.
  </Accordion>
  <Accordion title="Anti-spam" icon="shield">
    Activa reCAPTCHA o el filtro anti-spam del formulario. Valida email antes de enviar.
  </Accordion>
  <Accordion title="Rotación de la URL" icon="rotate">
    Si sospechas que la URL se ha filtrado, borra el webhook y crea otro. Actualiza el formulario con la nueva URL.
  </Accordion>
  <Accordion title="Trazabilidad" icon="clock-rotate-left">
    Guarda una copia del envío en tu base de datos o en una hoja de cálculo, no dependas solo de Discord como archivo.
  </Accordion>
</AccordionGroup>
