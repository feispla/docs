## Seguridad y privacidad

<Info>
  VANTCALL **nunca almacena las contraseñas** de tus cuentas de juego. El flujo OAuth te redirige al sitio oficial del proveedor para autenticarte, y solo recibimos un token de acceso limitado.
</Info>

<Warning>
  Si revocas el acceso de VANTCALL desde Discord, Google, Riot o Steam, tu cuenta seguira activa pero perderas la sincronizacion automatica de stats. Para desvincular sin perder el acceso, primero configura una contraseña propia desde los ajustes de cuenta.
</Warning>

<Tip>
  Podes tener **varios proveedores vinculados** simultaneamente. Por ejemplo: usa Discord para la comunidad, Riot ID para VALORANT y Steam para CS2, todo bajo la misma cuenta de VANTCALL.
</Tip>

## Desvincular un proveedor

1. Entra a **Cuenta > Proveedores vinculados**
2. Busca el proveedor que queres remover
3. Hace clic en **Desvincular**
4. Confirma con tu contraseña actual o 2FA si esta activo

<Note>
  Tenés que tener al menos **un metodo de acceso activo** en todo momento. Si solo tenes un proveedor y queres desvincularlo, primero agrega un email con contraseña o vincula otro proveedor.
</Note>
