VANTCALL permite iniciar sesión a través de plataformas de confianza para simplificar el registro y enriquecer tu perfil competitivo con datos verificables. Cada proveedor OAuth lee solo la información necesaria para su función específica.

## Seguridad y privacidad

<Info>
  VANTCALL **nunca almacena las contraseñas** de tus cuentas de juego. El flujo OAuth te redirige al sitio oficial del proveedor para autenticarte. Solo recibimos un token de acceso limitado.
</Info>

<Warning>
  Si revocas el acceso de VANTCALL desde Discord, Google, Riot o Steam, tu cuenta seguirá activa, pero perderás la sincronización automática de stats. Para desvincular sin perder el acceso, primero configura una contraseña propia desde los ajustes de cuenta.
</Warning>

<Tip>
  Puedes tener **varios proveedores vinculados** simultáneamente. Por ejemplo: usa Discord para la comunidad, Riot ID para VALORANT y Steam para CS2, todo bajo la misma cuenta de VANTCALL.
</Tip>

## Desvincular un proveedor

1. Entra a **Cuenta > Proveedores vinculados**
2. Busca el proveedor que quieres quitar
3. Pulsa **Desvincular**
4. Confirma con tu contraseña actual o 2FA si está activo

<Note>
  Tienes que tener al menos **un método de acceso activo** en todo momento. Si solo tienes un proveedor y quieres desvincularlo, primero agrega un email con contraseña o vincula otro proveedor.
</Note>
