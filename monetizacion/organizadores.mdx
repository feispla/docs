VANTS ofrece tres planes para organizadores de torneos, desde comunidades amateur hasta empresas que necesitan una plataforma de marca blanca con soporte dedicado. Cada plan escala en numero de participantes, formatos de bracket y opciones de personalizacion visual.

## Tabla comparativa de planes para organizadores

| Caracteristica | Community | Studio | Enterprise |
| --- | --- | --- | --- |
| Precio orientativo | Gratis | 49€/mes | Contacto comercial |
| Participantes maximo | 32 | 256 | Ilimitado |
| Brackets basicos | Si | Si | Si |
| Todos los formatos | No | Si | Si |
| Streaming API | No | Si | Si |
| Branding propio | No | Si | Si |
| Marca blanca | No | No | Si |
| Dominio propio | No | No | Si |
| SLA garantizado | No | No | Si |
| Integracion con proveedores autorizados | No | No | Si |

## Descripcion de cada plan

- **Community**: ideal para ligas amateur, torneos entre amigos o pruebas de concepto. Incluye brackets basicos y hasta 32 participantes sin coste.
- **Studio**: orientado a creadores de contenido, equipos semiprofesionales y organizaciones medianas. Por un precio orientativo de 49€/mes obtienes hasta 256 participantes, todos los formatos de bracket, acceso a la API de streaming para overlays y branding propio en la pagina del torneo.
- **Enterprise**: para empresas, federaciones y grandes organizaciones. Incluye marca blanca completa, dominio propio, SLA de disponibilidad, soporte prioritario e integracion directa con proveedores autorizados de pagos y verificacion de identidad.

<Steps>
  <Step title="Evalua tus necesidades">
    Define cuantos participantes esperas, si necesitas streaming API y si quieres branding personalizado.
  </Step>
  <Step title="Crea una cuenta de organizador">
    Registrate en VANTS y selecciona **Crear cuenta de organizador** desde el panel de perfil.
  </Step>
  <Step title="Elige Community o Studio">
    Selecciona el plan directamente desde **Configuracion > Plan de organizador**.
  </Step>
  <Step title="Solicita Enterprise (opcional)">
    Si necesitas marca blanca o dominio propio, haz clic en **Contactar con ventas** en la misma seccion y completa el formulario. El equipo comercial respondera en 2 a 3 dias habiles.
  </Step>
</Steps>

<Info>
  Los precios de Studio son orientativos. El importe final puede variar segun volumen de torneos, duracion del compromiso y servicios adicionales contratados.
</Info>
